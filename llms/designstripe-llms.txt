## API surface

There is no public API. Visual markets one on its homepage — "Product /
Integrations — Every agent is an endpoint. Integrate design agents with your
existing automation workflows or applications using our API." — but publishes
no developer portal, no API reference, no OpenAPI or AsyncAPI definition, no
GraphQL endpoint, no MCP server, no SDK on any package registry, and no
/.well-known/ discovery document on any host it controls.

The only API-shaped host, api.designstripe.com, resolves to a Google Cloud load
balancer that presents a TLS certificate for an unrelated host and answers every
request with a Google Cloud Identity-Aware Proxy challenge ("Invalid IAP
credentials: empty token"). It is an internal, authentication-gated host, not a
callable public API.
